# Israel Today — Hebrew Israel News

Hebrew-first, RTL Israel news website built with Next.js App Router.

## Stack
- Next.js 15
- React 19
- TypeScript
- RTL Hebrew layout
- Vercel-ready

## Run locally
```bash
npm install
npm run dev
```

## Important before launch
- Replace the temporary `israel-today.vercel.app` canonical/metadata URLs with the final verified domain.
- Add a real editorial workflow and verified sources before publishing news.
- Homepage cards are clearly marked as demonstration content; they are not live news.
- Add About, Contact, Privacy, Corrections, and Editorial Standards pages.
- Confirm brand/trademark availability. “ישראל היום” is already associated with an established Israeli newspaper; avoid confusing branding or copied visual identity.
